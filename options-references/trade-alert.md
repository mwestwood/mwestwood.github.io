## What It Is

Cboe Trade Alert sits at the more professional end of the flow/alerts spectrum. Where consumer-facing tools make configuration simple, Trade Alert exposes over 1,000 parameters for building custom alert triggers — and backs those triggers with explicitly OPRA-processed real-time data and a full API layer. It is built for traders, fintechs, and developers who need real-time options activity data with programmatic access.

---

## What It's Known For

- **Explicit OPRA real-time processing** — one of the few platforms to state this directly and publicly
- **1,000+ configurable alert parameters** — sweeps, blocks, unusual size, premium thresholds, and more
- **Streaming + REST APIs** — full programmatic access to the alert engine
- **Trade-level detail** — individual print data behind every alert
- **Volume processing** — marketed as filtering millions of trades per day

## Best For

- Active traders who need a high degree of alert customization
- Developers and fintechs building options flow features into their own products

---

## Strengths

- Clearest real-time data sourcing disclosure of any platform in this category
- Most configurable alert system in the retail-to-pro range
- API-first design makes it genuinely useful for developers
- Backed by Cboe — established institutional data infrastructure

## Weaknesses / Risks

- Pricing is substantially higher than consumer-focused flow tools
- Data fees add complexity to total cost calculation
- Even with real-time OPRA processing, bid/ask side inference remains a heuristic
- Retail-facing UX is secondary to the API/professional experience
